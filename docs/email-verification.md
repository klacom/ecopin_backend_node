# Atomic email verification

Apply `20261012110000` first, then `20261012143000`, before switching the backend to the new redemption handler. The backend calls only `redeem_email_verification_atomic`; it does not fall back to the older split Auth/profile operation when the routine is absent. A missing atomic routine returns retryable 503 without confirming Auth or consuming the token. Legacy links without recorded email binding require a new link after schema rollout.

The trusted public invoker RPC delegates to an unexposed, service-role-only definer with an empty search path. It locks the current Auth account and token, checks the issued and expected email against the authoritative current email, then confirms Auth, verifies/heals the citizen profile, and consumes the token in one transaction. No HTTP requests run under database locks. Concurrent callers can consume a token only once; any write failure rolls back all writes.

The custom confirmation routine preserves the reviewed GoTrue v2.197.0 User.Confirm state operations: confirmation timestamp/token, email_verified user metadata, and clearing the user's Auth one-time tokens. It changes account rows, not managed Auth schema definitions. Verify these column contracts and native login against the target Auth version before upgrades; source: https://raw.githubusercontent.com/supabase/auth/v2.197.0/internal/models/user.go. Roles are never taken from user metadata.

An expired link cannot newly confirm an account. A historical split-operation failure can finalize only when the recorded Auth confirmation lies within the token's original validity window and its bound email still matches. New requests cannot produce that partial state because all writes are atomic. Unbound historical links are rejected, not assigned a guessed email.

Rollback removes the new routines and preserves account/token state. It never unconfirms users or makes consumed tokens reusable. The new backend returns 503 until the migration is reapplied. Migration removal does not make the older split-operation handler safe.
